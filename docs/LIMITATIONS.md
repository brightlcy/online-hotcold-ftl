# Limitations

This is a Python mechanism simulator, not SSD firmware or a hardware benchmark. NAND parallelism, controller CPU scheduling, real NVMe queues and calibrated endurance are outside scope. WAF counts page programs; it does not establish device lifetime, energy, or real latency. Statistical evidence is limited to the recorded workloads and seeds. The implementation was assisted by AI; independent authorship of every line is not established.

The four policy workloads each contain 100,000 requests. Warm-up and measurement replay the same finite slice once each, not chronologically disjoint intervals. There is one deterministic run per policy/slice; repeated execution is not another independent sample. Devices were selected after a historical profile, so this is not a random or untouched external workload test. Target OP=20% differs from actual OP after block rounding; see each resolved geometry.

Historical Alibaba dev4 baseline and Hot/Cold manifests contain `latency_nonnegative=false`. Replayed logs show no negative total latency; two latency-versus-service comparisons per policy differ by at most 4.66e−10 us, consistent with strict floating-point comparison. WAF identities pass. Original source/diagnostics remain unchanged; timing claims stay outside headline results pending separate tolerance/model review. Historical plots/reports remain as evidence, not automatically endorsed current claims. dev740 is neutral; threshold 2 in MSR worsened modeled max latency. No broad causal claim follows from four slices. MSR replay and full-source streaming remain unavailable in this export.
